# Logo Picker

Веб-инструмент для подбора логотипов автосалонов. Чистые HTML, CSS и JavaScript без сборки и серверной части.

## Возможности

- 68 SVG-знаков, 19 шрифтов и 18 палитр шаблонов.
- Название сайта, выбор шаблона и шрифта, светлый и тёмный фон.
- Экспорт SVG со встроенным шрифтом, PNG-фавикона и ZIP-комплекта.
- БУ-6: красный и зелёный акценты; БУ-7 использует общую палитру `multi-bu / bu-7`.

## Структура

- `index.html` — интерфейс и логика генерации.
- `manifest.json` — список логотипов и шрифтов.
- `assets/palettes.json` — цвета и настройки шаблонов.
- `assets/logos/` — SVG-логотипы с `currentColor`.
- `assets/fonts/` — шрифты WOFF2.
- `lib/jszip.min.js` — упаковка файлов в ZIP.

## Локальный запуск

Запускайте через локальный HTTP-сервер, а не двойным кликом по HTML: приложение загружает JSON и SVG через fetch.

Например, при установленном Python: `python -m http.server 8000`, затем откройте `http://localhost:8000`.

## Совместные правки

Создавайте отдельную ветку и pull request. При добавлении логотипа обновляйте `manifest.json`, при добавлении палитры используйте уникальный ID. Не переименовывайте существующие ID без проверки зависимостей.

Перед объединением проверьте выбор шаблона, отображение на доступных фонах и скачивание комплекта.

## Netlify

Проект статический: команда сборки не нужна, каталог публикации — корень репозитория (`.`). Само размещение исходников на GitHub не подключает автоматический деплой.

В приложении сохранена существующая настройка Google Analytics. Для отдельной копии проверьте и замените идентификатор аналитики в `index.html`.
